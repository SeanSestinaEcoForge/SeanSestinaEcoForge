# Configs

- `pilot-v2.json` — family garage pilot defaults used by `api/`. Every value has `label`, `unit` and `source`.
- `future-node-ideas.json` — historical 40-ft node targets (700 gal, +16 kWh/day, 400 lb/mo, 96.5% RO). All **IDEA**, `runnable: false`, never used as defaults.

`source` fields cite sections of the family's private planning package, which is not yet public.
